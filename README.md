# YouTube Menu Downloader

Userscript для Tampermonkey / Violentmonkey: добавляет пункт **"Скачать"** в меню "..." под видео (рядом с "Пожаловаться") на YouTube, в Shorts и в YouTube Music.

Форматы:

| Формат   | Как скачивается                                   |
|----------|---------------------------------------------------|
| MP4      | cobalt, H.264 до 1080p, выше AV1                  |
| WEBM     | cobalt, VP9 + Opus                                |
| MP3      | cobalt, битрейт 64-320 кбит/с                     |
| Аудио    | cobalt, оригинальная дорожка без перекодирования  |
| Субтитры | напрямую с YouTube, SRT / VTT / TXT, с переводом  |

Для любого формата есть кнопка **yt-dlp**: она копирует готовую команду для [yt-dlp](https://github.com/yt-dlp/yt-dlp).

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или [Violentmonkey](https://violentmonkey.github.io/).
2. Откройте **[youtube-menu-downloader.user.js](https://raw.githubusercontent.com/DverkaSK/youtube-menu-downloader/main/youtube-menu-downloader.user.js)** и подтвердите установку. Обновления подтягиваются автоматически.
3. В Chrome 138+ включите для расширения переключатель **"Allow User Scripts"** (`chrome://extensions`, Tampermonkey, Details).

## Сервер cobalt

Видео и аудио скачиваются через [cobalt](https://github.com/imputnet/cobalt). Из коробки ничего настраивать не нужно: скрипт берёт бесплатный публичный сервер (`cobalt-api.kwiatekmiki.com`), и файл сразу качается в браузере. Если сервер не ответил, открывается веб-версия cobalt во вкладке, а ссылка на видео копируется в буфер обмена.

Публичные серверы бывают перегружены. Для стабильности можно поднять свой ([инструкция](https://github.com/imputnet/cobalt/blob/main/docs/run-an-instance.md)), он будет пробоваться первым. Проще всего локально через Docker из этого репозитория:

```sh
docker compose up -d
```

и указать в настройках скрипта адрес `http://localhost:9000/`.

Адрес API и ключ задаются в окне скрипта (кнопка "Настройки") или через меню Tampermonkey, пункт "Настройки". Кнопка "Проверить" показывает, отвечает ли сервер.

## Субтитры

YouTube отдаёт субтитры только с токеном, который плеер получает сам. Скрипт подхватывает его из запросов плеера. Если скачивание вернуло ошибку, включите субтитры (CC) в плеере на пару секунд и нажмите "Скачать" ещё раз.

## Ограничения

- Мобильная версия `m.youtube.com` не поддерживается.
- Пункт меню завязан на разметку YouTube. Если он пропал после обновления YouTube, диалог по-прежнему открывается через меню Tampermonkey, пункт "Скачать текущее видео".
